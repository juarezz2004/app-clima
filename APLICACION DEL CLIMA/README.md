# 🌤️ Aplicación del Clima en Tiempo Real

Aplicación web desarrollada en Python con Flask que permite consultar el estado meteorológico de cualquier ciudad del mundo en tiempo real mediante la integración de APIs REST externas.

## 🚀 Características
- **Búsqueda global:** Permite encontrar datos meteorológicos de cualquier ciudad mediante geocodificación.
- **Consumo de APIs REST:** Integración en tiempo real con Open-Meteo y Nominatim OpenStreetMap sin almacenamiento local.
- **Traducción e Interfaz Visual:** Mapeo de códigos WMO a condiciones meteorológicas en español con emojis descriptivos.
- **Diseño Responsive:** Interfaz oscura (Dark Mode) optimizada para dispositivos móviles y de escritorio.

## 🛠️ Tecnologías Utilizadas
- **Backend:** Python 3, Flask
- **Peticiones HTTP:** Librería `requests`
- **Frontend:** HTML5, CSS3 (Flexbox, Animaciones CSS)
- **APIs:** Open-Meteo API, Nominatim OpenStreetMap API
